# ЧАЙНА ИМПОРТ

Статический лендинг на HTML, CSS и JavaScript. Без сборки, фреймворков, backend и базы данных. Ресурсы локальные; сайт работает на бесплатном GitHub Pages и при открытии `index.html`.

## Дизайн

Весь сайт оформлен в одобренном стиле MagicPath: светлый фон, глубокий зелёный, крупная фотография без фона салона, заголовок «Из Китая. в ваш гараж.» и более крупные шрифты. Источник оформления — проект «ЧАЙНА ИМПОРТ — варианты нового дизайна», компонент `458643435331670016`, согласованная ревизия `458654429579730944`. Макет перенесён в обычные HTML/CSS, React и Tailwind для опубликованного сайта не требуются.

Каталог содержит четыре демонстрационные модели. Сохранены описание преимуществ, пять этапов покупки, информация о договоре, города доставки и все исходные контакты. Заголовки и текст используют Arial/Helvetica/system fallback. Фирменный логотип не перекрашен и не растянут.

## Просмотр

Откройте `index.html` или запустите локальный сервер:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:8000/ . Остановка: Ctrl+C. Python нужен только для этого необязательного сервера, для работы опубликованного сайта он не нужен.

## Анимации и звук

Логотип в шапке увеличен и немного выступает на светлый фон без увеличения высоты шапки. Кнопки и ссылки мягко подсвечиваются при наведении.

- Логотипы в шапке и подвале одинакового размера. Общая анимация длится 2,4 секунды: плавное уменьшение, оборот и мягкий возврат к большому размеру. Запускается при первом появлении в области просмотра, наведении мыши и фокусе с клавиатуры.
- Двухъярусный автовоз с четырьмя машинами едет из Китая в Россию. Его анимация приостанавливается за пределами экрана.
- Экономия растёт от 0 до 30%, когда видна сама цифра, затем свечение плавно затухает. При возвращении к блоку отсчёт повторяется. Итоговое значение остаётся видимым. Экранный диктор всегда получает «30 процентов».
- При наведении на большую фотографию автомобиль слегка вздрагивает и покачивается, фары кратко подсвечиваются. Первое наведение всегда беззвучно.
- Кнопка «Завести двигатель» запускает эффект со звуком. После первого клика наведения тоже могут воспроизводить звук. Кнопка «Звук: выкл.» отключает его; явный выбор пользователя сохраняется до перезагрузки страницы. На телефоне эффект доступен по кнопке.
- Звук и движение останавливаются при открытии окна подбора или уходе со страницы. Автоматического воспроизведения при загрузке нет. Отказ браузера в воспроизведении обработан.
- При `prefers-reduced-motion: reduce` движения, мерцание и прокрутка с анимацией отключены, сразу показаны 30%. Звук остаётся отдельным явным выбором пользователя. Без JavaScript контент и маршрут видимы, кнопки двигателя скрыты.

Кнопка «Звук» включает звук сайта: двигатель и тихий сигнал при наведении на ссылки и кнопки. До явного клика наведение бесшумно. Частые сигналы ограничены, во время запуска двигателя они не звучат. `assets/audio/ui-hover.wav` — оригинальный короткий синтезированный сигнал; перегенерация: `python scripts/generate_hover_audio.py`.

`assets/audio/engine-start.wav` — короткий оригинальный синтезированный эффект запуска и небольшого повышения оборотов с плавным затуханием. Это художественный звук, а не запись двигателя конкретной модели. Перегенерация средствами стандартной библиотеки Python:

```powershell
python scripts/generate_engine_audio.py
```

## Фотографии

Фотографии моделей, цены и характеристики — демонстрационные примеры, а не актуальное предложение. Перед заменой фотографии обновите название, параметры, цену, `alt` и `data-model` в `index.html`.

`hero-cutout.png` подготовлен встроенным imagegen из `hero-branded.webp`. Задание: убрать только фон салона и пол в прозрачность, сохранить фотографический вид белой Mazda CX-5, пропорции, ракурс, колёса, стёкла, отражения, эмблему и существующую табличку ЧАЙНА ИМПОРТ; сохранить весь автомобиль; без векторной или мультяшной стилизации. Изображение использовано для оформления макета; исходное фото сохранено.

В ранее подготовленных пяти фотографиях `*-branded.webp` через imagegen заменены дилерские таблички на логотип пользователя. Логотип с прозрачным внешним фоном также подготовлен ранее встроенным imagegen. Оригиналы фотографий и `logo-original.jpg` сохранены. Старый локальный шрифт Sagewold и его SIL OFL лицензия оставлены в `assets/fonts/`, в новом оформлении шрифт не подключается.

## Подбор и контакты

Кнопки подбора открывают окно с выбранной моделью и ссылками на Telegram, VK и телефон. Формы, хранения и отправки персональных данных на сайте нет. Окно закрывается кнопкой, Escape и кликом снаружи; фокус возвращается к исходной кнопке.

## Проверки

Для проверки поведения двигателя, звука, окна подбора и счётчика достаточно Node.js, зависимости не нужны:

```powershell
node tests/interactions.test.cjs
node --check script.js
git diff --check
```

Проверки покрывают беззвучное наведение, явный запуск, сохранение выключенного звука, отказ autoplay, устаревший ответ на запрос воспроизведения, остановку при уходе со страницы/открытии подбора, возврат фокуса и уменьшенное движение.

В браузере проверены ширины 320, 390, 768, 1024 и 1440 px, загрузка изображений и звука, меню, выбор модели, закрытие окна и возврат фокуса. На планшетах текст и фотография располагаются в отдельных колонках. На телефонах фотография находится над текстом, а запуск двигателя доступен по кнопке.

## GitHub Pages

Репозиторий публикуется через GitHub Pages. Все пути к ресурсам относительные и подходят для адреса проекта `/Landingtest-Chinaimport/`. Для публикации из ветки используются `main` и папка `/(root)`. Файл `.nojekyll` отключает обработку Jekyll. Ссылка на chinaimportspb.ru в контактах не задаёт домен GitHub Pages.
