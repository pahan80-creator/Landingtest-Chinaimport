# ЧАЙНА ИМПОРТ

Одностраничный статический лендинг. HTML, CSS и JavaScript без фреймворков, сборки, backend и базы данных. Все фотографии и шрифты локальные, внешние библиотеки не используются. Доставка — по всей России.

## Просмотр

Во время текущего сеанса: http://127.0.0.1:8000/

Можно также открыть `index.html` двойным щелчком — сайт работает без сервера.

Для повторного запуска локального сервера, если установлен Python, откройте терминал в этой папке:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8000/ . Остановка сервера: Ctrl+C.

## Замена фотографий

Замените файлы в `assets/images/`, сохранив их имена и формат:

- `hero-branded.webp` — первый экран;
- `qashqai-branded.webp` — Nissan Qashqai;
- `t-roc-branded.webp` — Volkswagen T-Roc;
- `cx-5-branded.webp` — Mazda CX-5;
- `x-trail-branded.webp` — Nissan X-Trail.

Файлы без суффикса `-branded` сохранены как исходные фотографии. `logo-original.jpg` — оригинальный логотип пользователя. В шапке и футере используется `logo-transparent.png` с прозрачным внешним фоном; белые буквы и внутренние обводки сохранены. Файл подготовлен встроенным imagegen с запросом: «Удалить только внешний белый фон в прозрачность, сохранить зелёные стрелки, белые надписи, внутренние обводки и пропорции. Без теней, свечения и новых элементов».

Рекомендуемая ширина: 1600–2500 пикселей. Фотографии карточек обрезаются по центру с небольшим смещением вниз. Положение регулируется через `object-position` в CSS. При смене модели обновите название, характеристики, цену, `alt` фотографии и `data-model` кнопки в `index.html`. Для другого формата измените расширение в `src`.

Использованы предоставленные фотографии, на всех пяти заменены таблички на фирменный логотип через встроенный инструмент imagegen. Итоговые изображения сохранены в `assets/images/*-branded.webp`. Оригиналы сохранены отдельно.

## Фирменное оформление

Sagewold используется для заголовков, моделей и крупных цифр. Для небольших пояснений и контактов оставлен Arial, чтобы сохранить читаемость. Шрифт подключён локально, поддерживает кириллицу. Автор: GGBotNet, лицензия SIL Open Font License 1.1, исходный текст в `assets/fonts/License.txt`. Страница автора: https://ggbot.itch.io/sagewold-font . Файл скачан из каталога https://www.dafont.com/sagewold.font .

Основной фирменный зелёный `#0d4e34` взят из предоставленного цифрового логотипа. Для текста на тёмном фоне используется светлый дополнительный оттенок `#8ac6a5`. Точное преобразование CMYK C90 M40 Y85 K45 в экранный цвет зависит от цветового профиля; сайт использует цвет оригинального JPG. Логотип не перекрашен и не растянут.

## Анимации и компактная шапка

Шапка занимает 96 px на компьютере и 80 px на телефоне. Фирменный шрифт сохранён в крупных заголовках; названия автомобилей, небольшие преимущества и этапы используют Arial для читаемости.

Первый экран появляется последовательно за 0,8 секунды. Карточки и этапы появляются при прокрутке с небольшими задержками. Маршрут «Китай → Россия» прорисовывается с движущейся точкой один раз при появлении в области просмотра. Окно подбора и его фон открываются плавно за 0,24 секунды. Эффекты задаются в `brand.css`, наблюдение за прокруткой — в `script.js`; внешних библиотек нет.

При `prefers-reduced-motion: reduce` анимации отключены и содержимое сразу доступно. Если настройка включается во время просмотра, наблюдение за прокруткой прекращается и все блоки открываются. Без JavaScript маршрут и содержимое остаются видимыми.

Логотип в шапке делает один оборот по часовой стрелке за 0,9 секунды после загрузки изображения, при наведении мыши и при фокусе с клавиатуры. После окончания оборота следующее наведение запускает новый. Уход курсора не прерывает вращение; область ссылки остаётся неподвижной. Настройка уменьшенного движения отключает этот эффект.

## Задание для обработки фотографий

Встроенный imagegen, по одному запросу для каждой фотографии: «Заменить только жёлтую переднюю табличку белой дилерской табличкой с предоставленным зелёным логотипом ЧАЙНА ИМПОРТ. Сохранить обе стрелки, надписи, обводки и пропорции логотипа; убрать прежние китайские надписи на табличке. Сохранить автомобиль, эмблему, колёса, свет, отражения, окружение и кадрирование 3:2; учесть перспективу таблички». Запрос применён к Nissan Qashqai, Volkswagen T-Roc, тёмной Mazda CX-5, Nissan X-Trail и белой Mazda CX-5 на первом экране. Это AI-редактирование для макета; исходные фото доступны для сравнения.

## GitHub Pages — после согласования версии

1. Создайте публичный репозиторий для бесплатной публикации.
2. Загрузите **содержимое этой папки** в корень репозитория, включая `.nojekyll`. Файл `index.html` должен лежать в корне, а не внутри дополнительной папки `china-import`.
3. В настройках репозитория откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Сохраните настройки.
5. После завершения публикации откройте ссылку, показанную в разделе Pages.

Сайт совместим с адресом вида `https://username.github.io/repository/`: ресурсы используют относительные пути `./`, якоря не требуют маршрутизации. Не добавляйте `CNAME`, если не подключаете собственный домен. Ссылка на chinaimportspb.ru в футере — контактная ссылка, она не настраивает домен проекта.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Демонстрационный контент

Модели, характеристики и цены — примеры, а не актуальное предложение. Audi из исходного примера заменён Nissan X-Trail, для которого есть предоставленная фотография; его параметры и цена также демонстрационные. Документ `1.docx` содержит учебные материалы, поэтому данные об автомобилях взяты из задания.

Кнопки подбора открывают окно с контактами, без формы, хранения или отправки данных. Ссылки Telegram, VK, сайта, электронной почты и телефонов взяты из задания.
